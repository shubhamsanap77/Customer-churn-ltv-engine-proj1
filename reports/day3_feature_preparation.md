# Day 3 Deliverable — Feature Preparation

Feature preparation for the ML stage:
1. Churn target identification and binary conversion.
2. Identifier removal.
3. Missing-value handling.
4. Categorical one-hot encoding.
5. Stratified 80/20 train-test split (`random_state=42`).
6. Export of X_train, X_test, y_train and y_test.

Generated ML-ready files are stored under `data/processed/day3_ml/`.
